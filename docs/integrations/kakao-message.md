# 카카오톡 일일 브리핑

한국시간 화요일부터 토요일까지 오전 9시에 실행되는 로컬 일일 루틴이 최신 정산 거래일까지 시장 데이터를 갱신한 뒤 카카오톡 `나와의 채팅`으로 시장 및 VO 브리핑을 전송하고 변경된 시장 CSV를 원격 저장소에 푸시한다. 토스증권은 등록된 공인 IP만 허용하므로 동적 IP를 사용하는 GitHub 호스티드 러너에서는 시장 데이터와 브리핑 루틴을 실행하지 않는다.

예약 실행을 놓친 날짜별 작업은 재생하지 않는다. 다음 정상 실행에서 최신 정산 거래일까지 한 번에 갱신하고 최신 거래일 브리핑 하나만 전송한다. 휴장일, 아직 장 마감 후 2시간이 지나지 않은 시점과 이미 완료한 거래일은 전체 루틴을 건너뛴다. 중간 실패 시 `.daily-routine-state.json`에 기록한 로컬 단계 상태를 이용해 같은 거래일의 브리핑이나 푸시를 이어서 처리한다.

## 브리핑 내용

- 최신 거래일 기준 IXIC, QQQ, TQQQ, SPY의 종가와 전일 종가 대비 변동률
- TQQQ의 최근 5거래일 수익률과 전체 역사에서의 방향별 극단도
- TQQQ 조정 종가의 최근 30거래일 수익률로 계산한 연율화 실현 변동성
- VO 기본 규칙에 따른 현재 TQQQ:현금 목표 비율
- 직전 거래일 신호와 현재 신호가 다를 때 다음 거래일 시가 리밸런싱 안내
- 신호 변경일에는 변경 전후 주식·현금 비율과 다음 거래일 시가 리밸런싱 안내만 표시한다. 계좌 조회와 주문수량 계산은 하지 않는다.

브리핑은 카카오톡 피드의 3:4 표시 비율과 상단 안전 여백을 반영한 800×1067 PNG 카드로 렌더링한다. 상승 행은 붉은색, 하락 행은 파란색으로 표시한다. VO 패널에는 현재 값, 전 거래일 대비 퍼센트포인트 변화와 반원형 계기판을 표시한다. 계기판은 0~120% 범위에서 60%와 90% 경계를 표시하며 바늘이 범위를 넘으면 양 끝에 고정한다. `권장 비중` 영역은 모든 상태에서 첫째 행을 주식, 둘째 행을 현금으로 고정한다. 기본 비중은 회색 막대로 표시하고, 비중이 늘어날 때에만 증가분을 주식은 붉은색, 현금은 파란색으로 구분한다. 비중이 줄어든 구간은 빈 막대로 표시한다. 신호 변경일에만 각 행의 비율을 `직전 → 현재`로 표시하며 행 글꼴, 위치와 막대 크기는 평상시 카드와 동일하게 유지한다.

## 움직임 극단도 기준

최근 움직임은 TQQQ 전체 구간인 1999-03-10 이후의 조정 종가를 사용한다. 2010-02-11 이전은 QQQ 기반 3배 합성 구간이며 카드에 `합성 포함`으로 표시한다. 비교 기간은 약 1주에 해당하는 5거래일로 고정한다.

현재 5거래일 종가 수익률을 같은 길이의 모든 과거 롤링 구간과 비교한다. 수익률이 양수이면 현재 이상으로 오른 구간, 음수이면 현재 이하로 빠진 구간을 같은 방향의 꼬리로 센다. 현재 구간과 같은 값도 꼬리 비율에 포함한다. `극단도`는 `100 × (1 - 꼬리 비율)`인 0~100 단일 점수이며 상승과 하락 모두 숫자가 높을수록 역사적으로 드문 움직임이다. 예를 들어 방향별 꼬리 비율이 2.0%이면 수익률 부호와 관계없이 `극단도 98.0`으로 표시한다.

움직임 극단도 패널은 별도 등급 문구 없이 극단도 점수에 따라 배경과 왼쪽 표시색만 바꾼다. 수익률 숫자는 상승을 빨강, 하락을 파랑으로 표시해 방향과 극단도를 분리한다.

- 99 이상: 빨강
- 95 이상 99 미만: 주황
- 80 이상 95 미만: 노랑
- 80 미만: 회색

서로 겹치는 롤링 구간도 매일 같은 기준으로 판단하기 위해 모두 포함한다. 따라서 극단도는 독립 사건의 발생 확률이나 재발 주기가 아니라, 과거의 모든 5거래일 관측치 중 현재 움직임이 놓인 상대적 위치다. 이 값은 가격 움직임의 역사적 희소성만 나타내며 호재·악재의 원인, 향후 방향 또는 매매 신호를 판정하지 않는다. 매매 판단은 아래 VO 신호를 별도로 따른다.

생성된 PNG는 저장소나 공개 이미지 호스팅에 기록하지 않는다. 로컬 임시 디렉터리에서 생성해 카카오 이미지 서버로 바로 업로드하고, 카카오가 반환한 이미지 URL을 피드 메시지에 사용한다. 카카오 서버의 업로드 이미지는 최대 100일 보관된 뒤 삭제된다.

VO 계산과 경계값은 [`docs/strategies/volatility-allocation/README.md`](../strategies/volatility-allocation/README.md)를 그대로 따른다. 신호는 최신 거래일 종가로 계산하며 주문 안내 시점은 다음 거래일 시가다.

## 자격증명

로컬 `.env`에 아래 값을 저장한다.

- `KAKAO_REST_API_KEY`
- `KAKAO_CLIENT_SECRET`
- `KAKAO_REFRESH_TOKEN`

로컬 브리핑 전송 중 카카오가 새 리프레시 토큰을 반환하면 `.env`의 `KAKAO_REFRESH_TOKEN`을 자동으로 교체한다. GitHub Pages 배포 실패 알림은 별도 GitHub Actions secrets의 같은 카카오 값과 `GH_SECRETS_TOKEN`을 계속 사용한다.

## 로컬 확인

카카오 앱 키 화면에서 REST API 키와 카카오 로그인용 클라이언트 시크릿을 각각 복사한 직후 다음 명령으로 로컬 `.env`에 저장할 수 있다. 값은 터미널에 출력되지 않는다.

```bash
python scripts/set_local_secret.py KAKAO_REST_API_KEY
python scripts/set_local_secret.py KAKAO_CLIENT_SECRET
```

최초 한 번 사용자 동의를 완료하고 리프레시 토큰을 `.env`에 저장한다.

```bash
python scripts/authorize_kakao.py
```

메시지를 전송하지 않고 브리핑 내용만 확인한다.

```bash
python scripts/send_daily_briefing.py --dry-run
```

`.env`에 카카오 자격증명이 설정된 이후 실제 메시지를 전송한다.

```bash
python scripts/send_daily_briefing.py
```

시장 데이터 갱신, 브리핑과 원격 동기화를 한 번에 실행한다.

```bash
.venv/bin/python scripts/run_daily_routine.py
```
