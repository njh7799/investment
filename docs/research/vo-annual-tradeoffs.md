# VO 연도별 수익과 비중 조절의 기회비용

분석 기준일과 데이터 종료일은 2026-10-30이다. Toss 가격으로 다시 계산한 기존 VO 기본 전략의 설명 조사이며, 새로운 매매 규칙을 탐색하거나 채택하는 연구가 아니다. 모든 결과는 1999-03-10부터 QQQ 기반 3배 합성과 관측 TQQQ를 이은 단일 전체 경로를 사용한다.

## 핵심 결과

- 100%에서 비중을 줄인 뒤 다시 100%가 될 때까지의 연속 구간은 **46개**다. 그중 TQQQ가 오른 구간은 **28개(60.86%)**, 감축하지 않았을 때보다 VO 수익률이 **5%p 이상 낮은 구간은 12개(전체 감축 구간의 26.08%)**다.
- 개별 감축 주문은 **80회**다. 직전 목표 비중이 100%였던 주문은 32회이며, 그중 수익률 기회비용 1%p 이상은 15회, 5%p 이상은 4회, 10%p 이상은 3회다.
- 목표 비중 100%를 유지한 동안 고점 대비 **10% 이상 하락한 사건은 71회**, **20% 이상은 33회**다. 이는 독립적인 약세장 개수가 아니라 비중 100% 구간 안에서 고점 회복 또는 감축으로 구분한 사건 수다.
- 과거 30일 수익률이 음수인데 전일 변동성이 60% 이하여서 100%를 유지한 상태는 **148구간·1,017거래일**이었다. 종료까지 손실인 구간은 40개, 5% 이상 추가 손실은 12개, 10% 이상은 5개다. 반대로 108개 구간은 상승했다.

## 계산 조건과 정의

[기본 VO](../strategies/volatility-allocation/README.md)를 그대로 사용했다. TQQQ 조정 종가 수익률 30개 표본표준편차를 연율화하고 60% 이하는 100%, 60% 초과~90% 이하는 50%, 90% 초과는 0%를 목표로 한다.

- 신호일 종가까지의 정보로 목표를 정하고 다음 거래일 시가에 정수 수량으로 체결하며, 종가로 평가한다.
- 시작 자산 100,000달러, 편도 체결금액의 0.1% 수수료, 현금 수익률·슬리피지·세금 0이다.
- 평가는 1999-03-10부터 2026-10-30까지 이어진 전체 합성 경로 하나만 사용한다. 2010년 상장일에 새 계좌를 시작하는 별도 경로는 만들지 않는다.
- 연 수익률은 전년 마지막 거래일 종가 평가액 대비 해당 연도 마지막 거래일 평가액이며 매년 계좌를 초기화하지 않는다. 1999년과 2026년은 부분 연도다.
- 표시 수치는 반올림 표기이며 CSV와 내부 계산은 원래 정밀도를 유지한다.

**상승 기회비용**은 목표 비중이 100%에서 50% 또는 0%로 내려간 날의 시가부터 100% 복귀 매수 직전 시가까지다. 감축 직전 주식 수량과 현금을 그대로 보유한 경우를 같은 시점의 VO와 비교한다. 50%와 0% 사이의 전환은 같은 연속 구간으로 묶고, 감축 기간의 수수료는 포함하되 종료 시점 재매수 비용은 양쪽 모두 제외한다.

개별 감축 분석은 50%→0%도 포함하고 직전 목표 비중 이상으로 돌아올 때 끝낸다. 비교 구간이 서로 겹칠 수 있으므로 연속 감축 구간과 구별한다.

**100% 보유 중 낙폭**은 100% 진입 시가, 각 거래일 종가, 다음 감축 직전 시가를 이어 관측한다. 같은 고점을 회복하거나 감축될 때 사건을 끝내며 당일 고가·저가는 사용하지 않는다. **하락 확인 뒤 추가 손실**은 시가 전에 알 수 있는 전일 기준 `30일 수익률 < 0`, `30일 변동성 ≤ 60%`, 적용 목표 100%가 이어지는 기간의 계좌 수익률이다.

고점·저점과 사후 구간 수익률은 설명용 라벨일 뿐 거래 신호에 소급하지 않았다. 구간별 수익률은 분모가 달라 합산할 수 없다.
