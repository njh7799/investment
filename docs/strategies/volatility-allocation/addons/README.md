# 변동성 배분 선택 addon

이 디렉터리는 기본 VO를 변경하지 않고 조합하는 추가 규칙을 기록한다. 현재 운용 프로필은 아래 두 addon을 기본 활성화한다. 카카오 브리핑의 SGOV 표시 구조는 사용자 선택 뒤 반영한다.

- **활성화:** [5/20 상향돌파·고변동성 구간당 1회 재진입](one-shot-sma-reentry.md): V자 반등 참여를 높이는 공격형 규칙
- **활성화:** [15거래일 독립층 SGOV 현금 운용](layered-sgov-cash-sleeve.md): 60%·90% 경계에서 생긴 현금 50%씩을 별도 확인해 운용하는 규칙
