# 전략 연구 방법론

이 문서는 모든 전략에 공통으로 적용하는 평가 기준을 정의한다. 연구 방향은 루트 [AGENTS.md](../../AGENTS.md), 전략별 규칙은 각 전략 README를 따른다.

## 평가 구간

- 평가 시작 전에 전략 README 또는 연구 기록에 고정·롤링 기간을 정하고, 전체 데이터 결과와 각 기간의 결과를 별도로 비교한다.
- 한 구간의 우수한 결과로 다른 구간의 부진을 상쇄하지 않고 구간별 결과를 함께 보고한다.
- 실제 TQQQ 상장 전 합성 데이터가 포함된 구간과 실제 데이터만 사용한 구간을 구분한다.

## 성과 지표

- **수익:** CAGR과 전체 수익률을 보고한다.
- **손실:** 전체 MDD와 고정·롤링 구간의 평균·최악 MDD를 보고한다.
- **Drawdown duration:** 직전 고점부터 저점까지의 기간으로 계산한다.
- **Recovery period:** 저점부터 직전 고점을 다시 회복할 때까지의 기간으로 계산한다.
- **Time underwater:** 직전 고점부터 그 고점을 완전히 회복할 때까지의 기간으로 계산한다.
- **거래 빈도:** 리밸런싱 체결일 수와 연평균 횟수를 보고한다. 같은 날의 리밸런싱은 한 번으로 센다.
- **비용 민감도:** 공통 수수료를 반영한 결과를 기본으로 하고, 필요하면 더 높은 비용에서의 변화를 별도로 보고한다.

최대 MDD 사건의 회복 지표와 전체 구간의 최장 Time underwater는 별도로 보고한다. 데이터 종료일까지 회복하지 못한 구간은 `미회복`과 종료일 기준 경과 기간을 표시한다.

## 판정과 기록

- TQQQ 단순 보유, QQQ 단순 보유와 VO 기본 전략을 공통 비교군으로 사용한다.
- 수익, 손실, 회복, 기간별 일관성, 규칙의 복잡도와 거래 빈도를 함께 판단한다.
- 특정 파라미터나 시장 구간에서만 우수한 결과는 채택 근거로 사용하지 않는다.
- 채택하지 않은 전략은 무효로 단정하지 않고, 현재 데이터·비용·목표에서 채택 근거가 부족한 이유를 [폐기 전략 기록](rejected-strategies.md)에 남긴다.
