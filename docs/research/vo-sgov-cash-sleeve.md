# VO 현금 구간의 SGOV 대체 비교

## 질문과 고정 규칙

기본 VO의 신호, `100% / 50% / 0%` TQQQ 목표 비중, 상태 변경 시에만 리밸런싱하는 규칙과 다음 거래일 시가 체결을 유지한다. 차이는 현금 목표 비중을 무수익 달러로 두는 대신 SGOV로 매수한다는 점뿐이다.

- 비교 기간: 공통 체결이 가능한 2020-05-28~2026-10-27
- 시작 자산: 100,000달러
- 매수·매도 수수료: [토스증권 미국주식 수수료](https://p.tossinvest.com/ko/open-api) 기준 0.1%. 주문별 총 체결금액이 10달러 이하면 무료이고, 0.01달러 미만 수수료는 절사
- 정수 수량만 거래하며 남는 금액은 무수익 현금으로 유지
- 세금과 슬리피지는 0
- TQQQ와 SGOV 모두 Toss의 분할조정 OHLC 사용

SGOV 가격에는 월별 분배금이 소급 반영되지 않으며 별도 배당 현금도 더하지 않는다. 따라서 이 연구의 SGOV 결과는 총수익이 아니라 분배금 제외 가격수익이다. 실제 SGOV 투자성과보다 낮게 평가되는 의도된 한계이며 저장소의 공통 시장 데이터 정책과 같다. [iShares 공식 분배 내역](https://www.ishares.com/us/products/314116/ishares-0-3-month-treasury-bond-etf)은 배당락일, 기준일, 지급일과 분배금을 별도로 제공한다.

## 결과

| 지표 | VO 현금 | VO SGOV | 차이 |
| --- | ---: | ---: | ---: |
| 최종 자산 | $612,092.36 | $598,962.57 | -$13,129.79 |
| 총수익률 | 512.09% | 498.96% | -13.13%p |
| CAGR | 32.63% | 32.19% | -0.45%p |
| MDD | -45.76% | -45.90% | -0.13%p |
| 최대 낙폭 회복일 | 2023-06-02 | 2023-06-02 | 동일 |
| 연평균 리밸런싱 체결일 | 8.42 | 8.42 | 0.00 |
| 총 수수료 | $7,732.34 | $15,231.46 | +$7,499.12 |

현금배당을 제외하면 SGOV의 월별 분배락은 가격 하락으로만 남는다. 여기에 SGOV 매매 수수료가 추가되어 최종 자산은 현금형보다 13,129.79달러 낮고 MDD도 0.13%p 깊었다. 따라서 현재 가격수익 기준에서는 SGOV를 VO 현금 구간의 수익 보강으로 사용할 근거가 없다.

수수료를 0으로 둔 민감도에서는 현금형과 SGOV형의 최종 자산이 각각 628,132.12달러와 630,838.83달러로 차이는 2,706.71달러, CAGR 차이는 0.09%p였다. 분배금을 제외한 SGOV 가격수익의 이점은 매우 작고, 편도 0.1% 비용을 적용하면 음수로 뒤집힌다.

## 재현

```bash
.venv/bin/python scripts/analyze_vo_sgov.py
.venv/bin/python scripts/analyze_vo_sgov.py --zero-fee --output /tmp/vo-sgov-zero
```

상세 지표, 연도별 수익률, 일별 자산 곡선과 입력 파일 해시는 `results/vo-sgov/`에 저장한다.
