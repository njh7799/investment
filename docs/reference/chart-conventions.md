# 가격·백테스트 차트 사양

모든 가격 및 백테스트 차트는 전체 거래일 데이터를 다운샘플링·집계·보간하지 않고 사용한다.

## 출력 형식

- 모든 차트는 확대, 시계열 탐색과 값 확인이 가능한 대화형 HTML을 항상 기본 산출물로 생성한다. 정적 이미지만 단독으로 제공하지 않는다.
- PNG가 필요하거나 함께 생성될 때는 아래 공통 표현과 16×8인치, 180 DPI 규격을 그대로 적용한다. 대화형 HTML도 색상, 선 두께, 사건 표시와 구간 구성 등 동일한 표현 규칙을 따른다.
- 대화형 차트의 툴팁에는 날짜와 표시 중인 각 시계열의 값을 원본 정밀도를 훼손하지 않는 범위에서 제공한다.

## 공통 표현

- 차트 기간의 사건은 [SPY 기준 주요 시장 하락 사건](market-events.md)에서 확인한다.
- 등록된 사건은 `#78909C`, 두께 `0.5`, 불투명도 `0.8`의 세로 점선으로 가격선과 모델선 뒤에 표시한다. 사건명은 X축 가까이에 두고 인접한 라벨은 세로 위치를 엇갈린다.
- 대화형 차트의 사건 툴팁에는 문서의 주요 배경을 포함한다. 문서에 없는 원인은 추측하지 않고 필요하면 당시 자료를 확인해 사건 문서를 먼저 갱신한다.
- 가격은 조정 종가를 `#222222`, 두께 `0.5`의 실선으로 표시한다.
- 기본 그리드는 표시하지 않고 X축은 1년 간격의 `YYYY` 형식을 사용한다.
- 기본 크기는 16×8인치, 출력은 여백을 정리한 180 DPI PNG로 한다.

## 모델 비교

- TQQQ 단순 보유와 QQQ 단순 보유를 기본 비교군으로 포함하고 모든 비교군의 시작 자산을 동일하게 맞춘다.
- TQQQ는 `#2979FF`, QQQ는 `#40C4FF` 두께 `0.5` 실선으로 표시한다.
- 비교 모델은 요청 순서대로 `#FF9100`, `#00C853`, `#D500F9`, `#FF1744`, `#AA00FF`, `#FFD600` 두께 `0.5` 실선을 사용한다.

최신 공통 거래일이 속한 달력연도를 기준으로 다음 구간을 생성한다. 각 구간은 첫 공통 거래일부터 마지막 공통 거래일까지 사용하고 경계를 중복하지 않는다.

1. 올해 1월 1일부터 최신 공통 거래일까지
2. 1년 전, 2년 전, 3년 전, 4년 전의 각 달력연도
3. 5년 전부터 9년 전까지
4. 10년 전부터 14년 전까지
5. 15년 전부터 19년 전까지
6. TQQQ 합성 데이터 시작일부터 20년 전 달력연도 말까지

예를 들어 최신 공통 거래일이 2026년이면 `2026년 YTD`, `2025년`, `2024년`, `2023년`, `2022년`, `2017–2021년`, `2012–2016년`, `2007–2011년`, `TQQQ 합성 시작–2006년` 차트를 생성한다.
