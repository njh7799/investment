# VO variants

이 디렉터리는 [VO 기본 전략](../)의 관측기간, 중간 비중 또는 목표 비중 함수를 대체하는 설정을 관리한다. 별도 명시가 없으면 여러 variant를 조합하지 않는다.

| variant | 대체 영역 |
| --- | --- |
| [40일 관측기간](40-day-lookback.md) | 30일 변동성 관측기간을 40일로 대체 |
| [중간 구간 25%](middle-band-25.md) | 60~90% 변동성 구간의 TQQQ 비중을 25%로 대체 |
| [중간 구간 40%](middle-band-40.md) | 60~90% 변동성 구간의 TQQQ 비중을 40%로 대체 |
| [거듭제곱 Target Volatility](power-target-volatility.md) | 계단식 비중을 연속 비선형 함수로 대체 |
