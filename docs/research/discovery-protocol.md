# 블라인드 공개 전략 조사 프로토콜

이 문서는 기존 전략과 성과에 끌려 후보를 선택하거나 결과를 본 뒤 규칙을 조정하는 편향을 줄이기 위한 조사 순서를 정의한다. 공개 전략 조사는 `탐색 → 원전 검증 → 사전등록 → 실행 → 통합` 순서를 지키며, 앞 단계에는 뒤 단계의 정보를 제공하지 않는다.

이 절차는 7차 이후 신규 조사부터 적용한다. 1~6차는 기존 연구 맥락을 본 상태에서 수행했으므로 소급해 블라인드 연구로 표시하지 않는다.

## 1. 블라인드 탐색

가능하면 컨텍스트를 상속하지 않은 조사 subagent를 사용한다. 조사자에게는 다음 정보만 제공한다.

- 장기 성장, 손실, 회복 속도, 기간 일관성, 간결성과 거래 효율을 함께 본다는 일반 목적
- 공개된 원저자·논문·공식 규칙으로 재현할 수 있어야 한다는 조건
- 사용 가능한 데이터의 자산 종류와 시계열 범위
- 미래정보 금지, 종가 신호와 다음 거래일 시가 체결, 공통 비용 규칙

다음 정보는 제공하지 않는다.

- VO와 기존 전략의 이름, 규칙과 성과
- `model-census.md`, 기존 배치 결과, 후보 및 폐기 목록
- 특정 전략군을 선호하거나 기존 기본 전략을 이겨야 한다는 조건

조사자는 후보별 1차 출처, 원문 목적, 정확한 기본 규칙, 필수 데이터, 저자가 고정한 파라미터와 재현상 불확실성만 제출한다. 검색 결과에 실린 성과 수치는 후보 선택 근거로 사용하지 않는다.

## 2. 독립 원전 검증

별도의 검증 subagent가 후보 규칙을 원문과 대조한다. 검증자에게도 기존 백테스트 결과는 제공하지 않는다.

- 기본 규칙과 저자의 예시·최적화 변형을 구분한다.
- 공식, 경계값, 준비기간, 리밸런싱 빈도와 자산 선택 수를 확인한다.
- 신호 시점과 주문 시점을 구분하고 미래정보 가능성을 확인한다.
- 대체 ETF, 합성 데이터와 현금수익률 등 원전과 다른 부분을 열거한다.
- 해석이 하나로 정해지지 않으면 구현하지 않고 `재현 불가`로 기록하거나, 결과 확인 전에 복수 해석을 별도 모델로 사전등록한다.

탐색자와 검증자의 해석 차이는 백테스트 전에 해결한다.

## 3. 사전등록

검증이 끝난 후보는 [`preregistrations/template.yaml`](preregistrations/template.yaml)을 복사해 배치 파일로 등록한다. 최소한 다음을 결과 실행 전에 고정한다.

- 후보 이름, 원문과 조사일
- 원문 목적과 독립 비교군
- 자산군, 신호 공식, 모든 파라미터와 경계 처리
- 준비기간, 평가·롤링·스트레스 구간
- 체결, 비용, 현금과 배당 처리
- 원전과 다른 구현 및 데이터 대체
- 실행 전략으로 분류할 역할별 판정 기준

사전등록 파일을 커밋한 뒤 본 실행을 시작하는 것을 원칙으로 한다. 결과를 본 뒤 규칙이나 파라미터를 바꾸지 않는다. 변경이 필요하면 원래 결과를 보존하고 새 식별자의 후속 연구로 등록한다.

## 4. 구현과 실행

- 사전등록을 기계적으로 구현하고 준비기간, 경계, 상태 변경과 다음 거래일 체결 테스트를 작성한다.
- 원시 결과에는 사전등록 파일, 코드 버전과 입력 자산 해시를 연결한다.
- 독립 비교군을 먼저 실행하고 VO·TQQQ·QQQ 비교는 별도 통합 표로 만든다.
- 전체, 고정, 5·10년 롤링, 스트레스와 비용 민감도 결과를 모두 보존한다.
- 실패하거나 불리한 결과도 삭제하지 않는다.

## 5. 사후 통합

통합 담당자만 이 단계에서 기존 연구 전체를 읽는다.

1. 신호, 자산군, 파라미터와 체결 규칙을 비교해 실질적 중복 여부를 판정한다.
2. 중복이면 새 전략으로 세지 않고 기존 조사 목록과 배치에 데이터·출처·구현 차이를 갱신한다.
3. 신규이면 `model-census.md`, 새 배치 보고서와 원시 결과를 추가한다.
4. [승격 기준](promotion-criteria.md)에 따라 독립 전략, VO 대체, VO addon 또는 연구 기록으로 분류한다.
5. 승격하지 않으면 이유와 재검토 조건을 `rejected-strategies.md`에 남긴다.

## 정보 누출 기록

조사자나 검증자가 기존 결과를 보았거나 후보의 공개 성과를 피할 수 없이 확인했다면 숨기지 않고 사전등록에 기록한다. 해당 연구는 완전 블라인드가 아닌 `부분 블라인드`로 표시하고 판정 신뢰도를 낮춘다.
