# 변동성 배분

VO(변동성 배분)는 TQQQ의 실현 변동성에 따라 TQQQ와 현금의 목표 비중을 조절하는 저장소의 기본 전략이다. 현재 운용 프로필은 이 기본 VO에 [5/20 상향돌파·고변동성 구간당 1회 addon](addons/one-shot-sma-reentry.md)을 활성화한다. 이 문서와 연결된 addon 문서만으로 현재 설정을 실행할 수 있으며 다른 관측기간과 중간 구간 비중, 거듭제곱 Target Volatility는 [대체 규칙](variants/)으로 관리한다.

기본 전략 위에 사용자가 명시적으로 더 높은 위험을 선택하는 규칙은 [addon](addons/)으로 분리한다. GitHub Pages에서는 addon을 끄고 기본 VO 결과와 즉시 비교할 수 있지만, 일일 운용과 카카오 브리핑은 활성화된 현재 프로필을 따른다.

별도 전략을 지정하지 않은 연구 비교군에는 addon 없는 기본 VO를 사용한다. 실제 운용 규칙·최신 리포트·알림에는 `VO + 5/20 addon` 프로필을 사용한다.

## 현재 운용 프로필

- 기본 VO의 30일 변동성 목표 비중을 먼저 계산한다.
- 기본 목표가 100% 미만일 때 5/20 상향돌파 addon을 결합한다.
- addon은 한 고변동성 구간에서 한 번만 시도하고 실제 매수가 이탈 시 addon 비중만 제거한다.
- 기본 VO 목표가 100%로 돌아오면 addon 상태를 초기화한다.
- 정확한 상태 전이와 체결 규칙은 [addon 문서](addons/one-shot-sma-reentry.md)를 따른다.

## 기본 설정

- 투자 대상은 TQQQ다.
- 변동성은 TQQQ 조정 종가의 일일 수익률로 계산하고 연율화한다.
- 신호는 거래일 종가까지 공개된 데이터로 계산하고 주문은 다음 거래일 시가에 체결한다.
- TQQQ 비중은 0~100%로 제한하며 공매도와 레버리지 대출을 사용하지 않는다.
- TQQQ는 정수 수량으로 거래하고 목표 수량의 소수점 이하는 버린다.
- 별도 조건이 없으면 매수와 매도 수수료는 각각 체결금액의 0.1%로, 현금 수익률, 슬리피지와 세금은 0으로 계산하고 비용 민감도는 결과에 별도로 제시한다.

## 실현 변동성

TQQQ 조정 종가의 최근 30거래일 일일 수익률 표준편차를 연율화한다.

```text
30일 변동성 = std(최근 30거래일 TQQQ 일일 수익률) × sqrt(252)
```

30개의 수익률이 쌓이기 전에는 TQQQ 목표 비중을 100%로 사용한다.

## 목표 비중

| 30일 변동성 | TQQQ | 현금 |
| ---: | ---: | ---: |
| 60% 이하 | 100% | 0% |
| 60% 초과 90% 이하 | 50% | 50% |
| 90% 초과 | 0% | 100% |

변동성이 경계값과 정확히 같으면 표의 위쪽 구간에 포함한다.

## 리밸런싱

- 종가 기준 목표 상태가 마지막으로 적용한 목표 상태와 다를 때만 주문을 만든다.
- 주문은 다음 거래일 시가에 새 목표 비중으로 체결한다.
- 한 번에 여러 경계를 통과하면 중간 상태를 생략하고 새 목표 비중으로 바로 리밸런싱한다.
- 같은 목표 상태에 머무는 동안에는 가격 때문에 실제 비중이 달라져도 추가 리밸런싱하지 않는다.

목표 비중은 상태 진입 시점에만 맞춘다. 이후 같은 상태에 머무는 동안에는 TQQQ 수량을 유지하므로 실제 비중은 가격에 따라 목표보다 높거나 낮아질 수 있다.

## 기본값 선택 근거

목표 비중이 `100% → 50% → 0%`로 단순하고, 20·30·40거래일 관측기간 비교에서 30일이 전체 CAGR과 연도별 평균 MDD의 균형이 가장 좋아 기본값으로 선택했다.

아래 표는 2026년 7월 27일까지의 전체 데이터로 기본값을 선정할 때 사용한 참고 결과다. 시작 자산은 100,000달러로 계산한 뒤 100으로 정규화했고, 현재 공통 기준과 달리 수수료를 반영하지 않았다. 현재 후보를 평가할 때는 이 표를 성과 기준으로 재사용하지 않고 [연구 방법론](../../research/methodology.md)과 0.1% 수수료를 적용해 다시 계산한다.

| 관측기간 | 전체 CAGR | 전체 MDD | 연도별 평균 MDD | 최악 5년 CAGR | 연평균 거래 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 20일 | 28.14% | -50.15% | -27.59% | 3.60% | 9.35 |
| 30일 | 32.40% | -52.72% | -26.33% | 7.26% | 5.84 |
| 40일 | 31.17% | -48.89% | -27.79% | 7.47% | 4.53 |

30일은 40일보다 전체 CAGR과 일반적인 롤링 구간의 성과가 높지만 최악 MDD는 더 크다. 40일은 최악 MDD, 하위권 5년 CAGR과 거래 빈도가 더 안정적이므로 방어 성향의 대체 설정으로 유지한다. 20일은 거래가 크게 늘면서 장기 성과와 롤링 하한이 모두 낮아 후보에서 제외한다.
