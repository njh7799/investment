# 연구 후보

아직 VO 기본 전략을 대체하거나 addon으로 승격할 후보가 없다.

1차 배치에서는 실제 TQQQ 기간, 최근 10년, 5·10년 롤링 기간의 수익·MDD·회복 기간을 함께 비교했을 때 VO보다 일관되게 좋은 모델이 없었다. 상세 결과는 [1차 배치 보고서](batches/01-single-asset-timing.md)를 따른다.

2차 BLL 규칙도 후보를 만들지 못했다. 최근 10년에는 일부 장기 VMA가 강했지만 실제 전체·합성 전체·롤링 최악 구간에서 수익과 위험의 일관성이 깨졌다. 상세 결과는 [2차 배치 보고서](batches/02-bll-technical-rules.md)를 따른다.

3차의 GTAA 5와 GEM은 낙폭을 줄였지만 VO를 대체하기에는 수익 격차가 지나치게 컸다. 별도 저위험 포트폴리오 연구 대상으로만 남기며 기본 전략은 바꾸지 않는다. 상세 결과는 [3차 배치 보고서](batches/03-multi-asset-allocation.md)를 따른다.

4차 PAA2도 MDD -14.33%라는 방어력은 확인했지만 공통기간 CAGR 5.54%와 975일의 최장 TUW로 VO의 성장·회복 목표를 충족하지 못했다. 후보로 승격하지 않는다. 상세 결과는 [4차 배치 보고서](batches/04-paa2.md)를 따른다.
