# 공개 투자 모델 조사 프로그램 요약

공개 모델 조사는 2026년 8월 3일 기준 데이터로 시작해 11개 배치로 확장했다. 이동평균 내부 확장, 방어형 다중자산, 블라인드 탐색 FAA, VO 상승 참여, ERC 재현성 감사, Permanent Portfolio와 조던 나스닥 -3% 규칙을 순서대로 추가했으며 최신 배치는 2026년 8월 12일까지의 데이터를 사용한다. 7차부터는 각 전략을 독립 비교군으로 먼저 판정하고, 저장소 역할을 확인할 때만 VO와 TQQQ·QQQ 보유를 통합 비교군으로 사용한다.

## 최종 판단

- 현재 목표에서는 **VO 30일 기본 규칙을 유지**한다. 조사한 모델 중 여러 고정·롤링 기간에서 수익, MDD와 회복기간을 함께 의미 있게 개선한 모델은 없다.
- 최근 10년만 보면 장기 VMA와 TQQQ 보유가 강하지만 닷컴 합성 구간, 실제 전체와 롤링 최악 시작점에서 우위가 무너진다. 최근 구간만으로 채택하면 데이터 스누핑이 된다.
- GTAA와 PAA는 MDD를 크게 줄이지만 위험 노출과 복리수익 자체를 대부분 낮춘다. 이는 VO의 개선이라기보다 별도 저위험 포트폴리오 선택이다.
- 신규 VO 기본 전략이나 addon으로 승격한 모델은 없다. Permanent Portfolio 15/35는 다른 저위험 목적의 독립 게이트를 통과해 외부 참고 전략으로 승격했으며 VO 기본값은 바꾸지 않는다.
- 이동평균을 VO의 증감 조건에 결합해도 수익 개선과 하락 방어가 함께 재현되지 않았다. 50일 확인형 하나만 고르면 파라미터 사후선택이 된다.
- 위험조정 추세, 변동성 냉각, 시장 폭과 확인형 회복을 결합해도 통과형의 양의 초과수익이 대부분 2020년에 집중됐다. 같은 사건이 포함된 여러 롤링 구간을 독립 반복으로 세지 않는다.

## 셀프 리뷰

- **미래정보:** 종가 신호는 다음 거래일 시가에 체결했다. 월말 모델도 월말 종가로 같은 날 체결하지 않았다.
- **사전등록:** 결과를 본 뒤 룩백·밴드·Top 수·breadth를 바꾸지 않았다. 인접 파라미터 최고값을 새 기본값으로 고르지 않았다.
- **데이터:** TQQQ 상장 전만 QQQ 3배 합성을 허용했다. 다른 ETF는 실제 상장 이후 공통기간만 사용했다.
- **비교 한계:** 외부 장기 지수를 ETF로 치환한 결과에는 상품선택·생존자 편향과 짧은 공통기간이 있다.
- **비용:** 편도 0.1%를 기본으로 하고 0.2%·0.5% 민감도를 저장했다. 세금·슬리피지·현금수익률은 0이다.
- **거래 횟수:** 같은 날 여러 자산 주문을 하나의 리밸런싱으로 세며 월별 정기 재조정도 반영했다.
