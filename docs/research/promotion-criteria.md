# 연구 결과의 분류와 승격 기준

이 문서는 결과를 본 뒤 유리한 기준을 고르는 일을 막기 위해 저장소 역할별 판정 원칙을 정의한다. 배치 사전등록에는 아래 공통 기준과 전략 목적에 맞는 추가 기준을 결과 실행 전에 적는다.

## 공통 필수 조건

`docs/strategies/`로 승격하려면 다음을 모두 충족해야 한다.

- 원문 또는 공개 규칙을 한 가지 의미로 재현할 수 있다.
- 미래정보 없이 실행되고 다음 거래일 체결 테스트를 통과한다.
- 전체·고정·롤링·스트레스·비용 민감도 결과가 보존돼 있다.
- 결과를 본 뒤 선택한 단일 파라미터가 아니며 인접 설정 또는 독립 근거가 규칙을 지지한다.
- 기본 규칙을 전략 README 하나만으로 실행할 수 있다.
- 연평균 리밸런싱 20회 이내다. 초과하면 높은 비용에서도 목적상 우위가 유지돼야 한다.

## 독립 실행 전략

VO와 목적이 다른 전략은 원문의 목적과 사전등록한 독립 비교군으로 판정한다.

- 적어도 두 개의 주요 고정 구간과 5·10년 롤링 중앙값에서 독립 비교군보다 목적 지표가 개선돼야 한다.
- 롤링 최악 구간과 스트레스 결과가 전략의 주장과 모순되지 않아야 한다.
- 수익을 낮춰 MDD를 줄이는 전략은 수익·MDD·TUW의 교환관계를 수치로 명시한다.
- 기준을 충족하면 `독립 전략` 또는 원전 재현 목적의 `외부 참고 전략`으로 승격할 수 있다. VO보다 CAGR이 낮다는 사실만으로 탈락시키지 않는다.

## VO 대체 후보

동일한 TQQQ 장기 성장 목적의 모델은 사전등록에서 더 엄격한 값을 정할 수 있으며, 기본 하한은 다음과 같다.

- 실제 TQQQ 전체와 최근 10년 CAGR이 각각 VO의 90% 이상이다.
- 전체 MDD를 5%p 이상 낮추거나 최장 TUW를 10% 이상 단축한다.
- 개선하지 않은 MDD 또는 TUW가 VO보다 5% 이상 악화되지 않는다.
- 5·10년 롤링 최악 CAGR이 각각 VO의 80% 이상이고, 개선 방향이 한 구간에만 의존하지 않는다.
- 편도 수수료 0.2%에서도 위 조건의 방향이 유지된다.

조건을 통과한 모델만 기본 VO와 교체 여부를 검토한다. 한 조건에 근접한 모델은 `VO 대체 관찰 후보`로 연구 문서에 남길 수 있지만 실행 기본값으로 승격하지 않는다.

## VO addon 후보

- 실제 TQQQ 전체와 최근 10년 CAGR이 각각 기본 VO의 95% 이상이다.
- 전체 MDD를 5%p 이상 낮추거나 최장 TUW를 10% 이상 단축한다.
- 5·10년 롤링 최악 CAGR 중 어느 것도 VO보다 10% 넘게 낮지 않다.
- 편도 수수료 0.2%와 인접 파라미터에서도 개선 방향이 유지된다.
- 추가 신호가 막은 손실과 놓친 상승을 사건별로 공개해 특정 사건 하나에만 의존하지 않음을 확인한다.

## 판정 명칭

| 판정 | 의미 | 기록 위치 |
| --- | --- | --- |
| 재현 실패 | 공개 규칙을 한 가지 의미로 구현할 수 없음 | 조사 목록·폐기 기록 |
| 독립 목적 미달 | 원문의 목적에 맞는 비교군에도 근거 부족 | 배치·폐기 기록 |
| 연구 기록 | 특성은 확인했지만 실행 승격 기준 미달 | 배치·폐기 기록 |
| 독립 전략 후보 | VO와 다른 목적에서 공통 조건 통과 | 후보 문서 |
| VO 대체 관찰 후보 | 일부 대체 기준에 근접하나 미충족 | 후보 문서 |
| VO 대체 후보 | 대체 기준 전체 통과 | 후보 문서·전략 초안 |
| VO addon 후보 | addon 기준 전체 통과 | 후보 문서·addon 초안 |

승격 후보가 생기면 결과를 다시 최적화하지 않고 문서·구현 검토를 거쳐 `docs/strategies/`에 추가한다. 기본 VO 변경은 독립적인 미관측 기간에서 같은 방향이 확인된 뒤 별도로 결정한다.
