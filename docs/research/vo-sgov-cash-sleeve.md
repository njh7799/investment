# VO 현금 구간의 SGOV 대체 비교

## 질문과 고정 규칙

기본 VO의 신호, `100% / 50% / 0%` TQQQ 목표 비중, 상태 변경 시에만 리밸런싱하는 규칙과 다음 거래일 시가 체결을 유지한다. 차이는 현금 목표 비중을 무수익 달러로 두는 대신 SGOV로 매수한다는 점뿐이다.

- 비교 기간: SGOV 실제 데이터가 존재하는 2020-06-01~2026-08-28
- 시작 자산: 100,000달러
- 매수·매도 수수료: [토스증권 미국주식 수수료](https://p.tossinvest.com/ko/open-api) 기준 0.1%. 주문별 총 체결금액이 10달러 이하면 무료이고, 0.01달러 미만 수수료는 절사
- 정수 수량만 거래하며 남는 금액은 무수익 현금으로 유지
- 세금과 슬리피지는 0
- TQQQ와 SGOV 모두 Yahoo Finance의 배당·분할 조정 OHLC 사용

SGOV 조정 OHLC에는 분배금이 배당락일에 재투자된 총수익이 반영된다. 따라서 월별 분배금과 12월의 추가 분배도 배당락일 기준으로 포함되지만, 실제 지급일까지 며칠간 현금이 묶이는 효과와 배당세는 포함하지 않는다. 이 가정은 저장소의 공통 시장 데이터 정책과 같다. [iShares 공식 분배 내역](https://www.ishares.com/us/products/314116/ishares-0-3-month-treasury-bond-etf)은 배당락일, 기준일, 지급일과 분배금을 별도로 제공한다. 분석 종료일까지 Yahoo Finance 조정에 반영된 SGOV 분배는 2020-07-01~2026-08-03의 71회다.

## 결과

| 지표 | VO 현금 | VO SGOV | 차이 |
| --- | ---: | ---: | ---: |
| 최종 자산 | $630,367.34 | $638,374.53 | +$8,007.18 |
| 총수익률 | 530.36% | 538.37% | +8.00%p |
| CAGR | 34.32% | 34.59% | +0.27%p |
| MDD | -45.76% | -45.69% | +0.07%p |
| 최대 낙폭 회복일 | 2023-06-02 | 2023-06-01 | 1일 단축 |
| 연평균 리밸런싱 체결일 | 8.49 | 8.49 | 0.00 |
| 총 수수료 | $7,408.60 | $14,858.43 | +$7,449.83 |

SGOV 매매 수수료가 추가되어 총 수수료가 거의 두 배가 되었는데도 최종 자산은 8,007.18달러 증가했다. 다만 비교 기간 대부분의 위험과 수익은 TQQQ가 지배하므로 MDD 개선은 0.07%p로 매우 작다. SGOV는 VO의 방어 규칙 자체를 바꾸기보다는 현금 구간의 소폭 수익 보강으로 해석하는 편이 맞다.

수수료를 0으로 둔 민감도에서는 현금형과 SGOV형의 최종 자산이 각각 646,579.60달러와 671,743.87달러로 차이가 25,164.26달러, CAGR 차이가 0.82%p였다. 기본 결과와의 큰 차이는 SGOV 수익의 상당 부분이 잦은 양방향 0.1% 매매 비용에 소모됨을 뜻한다.
