# 전략 연구 방법론

이 문서는 모든 전략에 공통으로 적용하는 평가 기준을 정의한다. 연구 방향은 루트 [AGENTS.md](../../AGENTS.md), 탐색 절차는 [블라인드 조사 프로토콜](discovery-protocol.md), 승격 판정은 [승격 기준](promotion-criteria.md), 전략별 규칙은 각 전략 README를 따른다.

## 평가 순서

평가는 아래 순서를 바꾸지 않는다.

1. 전략의 원문 목적과 규칙에 맞는 독립 비교군을 사전등록한다.
2. 기존 연구 결과를 참조하지 않고 규칙 해석과 미래정보 여부를 검증한다.
3. 독립 성과를 산출해 전략 자체의 특성과 재현 여부를 판정한다.
4. 그 뒤에만 VO·TQQQ·QQQ 및 기존 연구와 비교해 저장소에서의 역할을 판정한다.

VO보다 CAGR이 낮다는 이유만으로 저위험·분산·인컴 등 목적이 다른 전략을 무효로 판정하지 않는다. 반대로 독립 목적을 달성했다는 이유만으로 VO 대체나 addon으로 승격하지 않는다.

## 평가 구간

- 평가 시작 전에 사전등록 문서에 고정·롤링 기간, 스트레스 구간과 독립 비교군을 정하고, 전체 데이터 결과와 각 기간의 결과를 별도로 비교한다.
- 한 구간의 우수한 결과로 다른 구간의 부진을 상쇄하지 않고 구간별 결과를 함께 보고한다.
- 실제 TQQQ 상장 전 합성 데이터가 포함된 구간과 실제 데이터만 사용한 구간을 구분한다.

## 성과 지표

- **수익:** CAGR과 전체 수익률을 보고한다.
- **손실:** 전체 MDD와 고정·롤링 구간의 평균·최악 MDD를 보고한다.
- **Drawdown duration:** 직전 고점부터 저점까지의 기간으로 계산한다.
- **Recovery period:** 저점부터 직전 고점을 다시 회복할 때까지의 기간으로 계산한다.
- **Time underwater:** 직전 고점부터 그 고점을 완전히 회복할 때까지의 기간으로 계산한다.
- **거래 빈도:** 리밸런싱 체결일 수와 연평균 횟수를 보고한다. 같은 날의 리밸런싱은 한 번으로 센다.
- **비용 민감도:** 공통 수수료를 반영한 결과를 기본으로 하고, 필요하면 더 높은 비용에서의 변화를 별도로 보고한다.

최대 MDD 사건의 회복 지표와 전체 구간의 최장 Time underwater는 별도로 보고한다. 데이터 종료일까지 회복하지 못한 구간은 `미회복`과 종료일 기준 경과 기간을 표시한다.

## 판정과 기록

- 독립 평가에는 전략의 주장과 위험 수준에 맞는 사전등록 비교군을 사용한다. 정적 동일 자산배분, 해당 기초자산 보유 또는 60/40처럼 규칙이 단순한 비교군을 우선한다.
- TQQQ 단순 보유, QQQ 단순 보유와 VO 기본 전략은 저장소 역할을 판정하는 통합 비교군이며, 모든 전략의 독립 성패 기준으로 사용하지 않는다.
- 수익, 손실, 회복, 기간별 일관성, 규칙의 복잡도와 거래 빈도를 함께 판단한다.
- 특정 파라미터나 시장 구간에서만 우수한 결과는 채택 근거로 사용하지 않는다.
- 판정은 `재현 실패`, `독립 목적 미달`, `연구 기록`, `독립 전략 후보`, `VO 대체 후보`, `VO addon 후보`를 구분한다.
- 실행 전략으로 승격하지 않은 모델은 무효로 단정하지 않고, 현재 데이터·비용·목표에서 승격 근거가 부족한 이유를 [폐기 전략 기록](rejected-strategies.md)에 남긴다.
