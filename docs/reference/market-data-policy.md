# 시장 데이터 정책

## 공통

- 데이터 출처는 Yahoo Finance이며 액면분할과 배당이 반영된 조정 OHLC를 원본 정밀도로 저장한다.
- ETF가 상장되기 전 기간을 다른 ETF로 합성하지 않는다. 유일한 예외는 별도 한계가 문서화된 TQQQ 상장 전 QQQ 3배 합성 구간이다.
- 여러 자산을 비교할 때 모든 필수 자산에 실제 데이터가 존재하는 공통 거래일부터 시작한다.
- ETF는 원전의 총수익 지수를 완전히 재현하지 않는다. 운용보수, 추적오차, 지수 방법론 차이와 생존자 편향을 결과에 명시한다.

## 현재 프록시

| 연구 자산군 | ETF | 용도 |
| --- | --- | --- |
| 미국 주식 | SPY | S&P 500 프록시 |
| 미국 외 주식 | EFA, VEU | 선진국 및 ACWI ex-US 프록시 |
| 미국 국채·채권 | IEF, AGG | 7–10년 국채 및 종합채권 프록시 |
| 부동산 | VNQ | 미국 리츠 프록시 |
| 원자재 | DBC | 광범위 원자재 프록시 |
| 금 | GLD | 금 프록시 |

현금 수익률은 공통 백테스트 가정에 따라 0이다. 원전이 T-bill을 비교 기준이나 안전자산으로 사용하면 그 차이를 모델 문서와 결과에 표시한다.
