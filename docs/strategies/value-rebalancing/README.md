# 라오어 VR 5.0 참고 전략

VR(Value Rebalancing)은 TQQQ 평가금을 2주마다 갱신하는 목표값 `V`의 밴드 안에서 관리하는 전략이다. 이 문서는 다른 전략과 동일한 초기 자산으로 비교하기 위한 **거치식 VR 5.0 기준 프로필**을 정의한다. 저장소의 기본 전략이나 자체 연구 후보가 아니라 외부 방법론을 공통 체결 규칙으로 비교하는 참고 전략이다.

## 핵심 규칙

- `V`: 목표 TQQQ 평가금
- `P`(Pool): 보유 현금
- `G`(Gradient): V의 증가 속도를 조절하는 값
- TQQQ 평가금: 보유 수량 × 현재 가격

거치식은 외부 적립과 인출 없이 다음 공식을 2주마다 적용한다.

```text
다음 V = 현재 V + P / G
상단 = V × 1.15
하단 = V × 0.85
```

- TQQQ 평가금이 상단을 초과하면 평가금이 `V`가 되도록 일부 매도하고 대금을 Pool에 넣는다.
- TQQQ 평가금이 하단보다 낮으면 평가금이 `V`가 되도록 매수하되, 해당 사이클 시작 시점 Pool의 50%까지만 사용한다.
- 평가금이 밴드 안에 있으면 거래하지 않는다.
- Pool이 부족하면 가능한 정수 수량만 매수하며 별도 자금을 투입하지 않는다.

## 저장소 비교 프로필

| 항목 | 설정 |
| --- | --- |
| 종목 | TQQQ |
| 유형 | 거치식 |
| 초기 배분 | TQQQ 90%, 현금 10% |
| 사이클 | 10거래일 |
| G | 10 |
| 밴드 | V 기준 ±15% |
| 사이클당 매수 한도 | 시작 시점 Pool의 50% |
| 목표 평가금 | 매수·매도 후 V |
| 수량 | 정수, 소수점 이하 버림 |
| 외부 적립·인출 | 없음 |
| 현금 이자·거래비용·세금 | 기본 비교에서는 0 |

초기 배분과 10거래일 사이클은 일별 데이터로 고정 자산 백테스트를 수행하기 위한 저장소의 비교 가정이다. 원 방법론의 `2주`는 달력 주기이므로 요청에서 실제 운용일을 지정하면 그 설정을 우선하고 결과에 차이를 명시한다.

## 저장소 체결 방식

매매 신호는 거래일 종가로만 판단하고 다음 거래일 시가에 체결한다.

- 종가 기준 TQQQ 평가금이 상단보다 높거나 하단보다 낮을 때만 주문을 확정한다.
- 다음 거래일 시가는 체결 가격으로만 사용하며 밴드 충족 여부를 다시 판단하지 않는다.
- 체결 시가에서 TQQQ 평가금이 `V`가 되도록 정수 수량을 계산한다.
- 매수는 신호가 발생한 사이클의 남은 매수 한도와 Pool 안에서만 체결한다.
- 데이터 마지막 날의 신호는 다음 거래일 시가가 없으므로 미체결로 남긴다.
- 포트폴리오 가치는 각 거래일 종가로 평가한다.

이는 일별 데이터의 장중 체결 순서 가정을 없애기 위한 저장소 비교 방식이다. 원 방법론의 지정가 주문 체결을 그대로 재현하지 않으므로 결과를 해석할 때 이 차이를 명시한다.

## 비교 시 주의사항

- 적립식과 인출식은 외부 현금 흐름 때문에 고정 초기 자산 전략과 CAGR을 직접 비교하기 어렵다. 별도 요청이 없으면 거치식만 사용한다.
- VR은 하락 시 Pool을 사용해 TQQQ를 추가 매수하므로 장기 하락장에서 Pool이 소진되면 방어력이 크게 약해질 수 있다.
- 2010년 2월 이전 비교에는 실제 TQQQ가 아닌 QQQ 기반 합성 데이터가 포함된다.
- VR은 개정 이력이 있으므로 결과에는 `VR 5.0 거치식 비교 프로필`이라고 버전을 표시한다.
