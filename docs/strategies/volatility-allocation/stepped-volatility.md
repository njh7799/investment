# 계단형 변동성 배분

이 문서는 연구 과정에서 `V1`으로 부르는 계단형 변동성 배분 규칙을 정의한다. 공통 계산과 체결 방식은 [변동성 배분](README.md)을 따른다.

## 변동성

TQQQ 조정 종가의 최근 30거래일 일일 수익률 표준편차를 연율화한다.

```text
30일 변동성 = std(최근 30거래일 TQQQ 일일 수익률) × sqrt(252)
```

30개의 수익률이 쌓이기 전에는 TQQQ 목표 비중을 100%로 사용한다.

## 목표 상태

| 30일 변동성 | TQQQ 목표 비중 | 현금 목표 비중 |
| ---: | ---: | ---: |
| 60% 이하 | 100% | 0% |
| 60% 초과 80% 이하 | 50% | 50% |
| 80% 초과 | 25% | 75% |

경계값과 정확히 같은 경우에는 표의 위쪽 구간에 포함한다.

## 리밸런싱

- 종가 기준 목표 상태가 마지막으로 적용한 목표 상태와 달라질 때만 주문을 만든다.
- 주문은 다음 거래일 시가에 새 목표 비중으로 체결한다.
- 한 번에 여러 경계를 통과하면 중간 상태를 거치지 않고 새 목표 비중으로 바로 리밸런싱한다.
- 같은 목표 상태에 머무는 동안에는 가격 때문에 실제 비중이 달라져도 추가 리밸런싱하지 않는다.

25%는 지속적으로 유지하는 최저 보유 비중이 아니다. 25% 상태에 진입할 때만 총자산의 25%에 맞추며, 이후 TQQQ 가격이 하락해도 수량을 유지하므로 실제 TQQQ 비중은 25%보다 낮아질 수 있다. 반대로 가격이 상승하면 실제 비중은 목표보다 높아질 수 있다.

현재 규칙에는 진입·복귀 경계를 다르게 두는 히스테리시스가 없다. 변동성이 경계값을 반복해서 넘나들면 상태 변경과 매매가 반복될 수 있다.

V1 이후의 탐색 결과는 [계단형 변동성 후보](stepped-volatility-candidates.md)에서 관리한다. 히스테리시스를 사용하는 후보는 공통 [히스테리시스 추가 규칙](addons/hysteresis.md)을 함께 적용한다.
