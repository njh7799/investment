# 변동성 경계 히스테리시스

이 추가 규칙은 계단형 변동성 배분에서 변동성이 상승할 때의 위험 축소 경계와 하락할 때의 복귀 경계를 분리한다. 경계 부근을 반복해서 오갈 때 생기는 잦은 매매를 줄이는 것이 목적이다.

## 상태 전이

기본 위험 축소 경계를 `T`, 모든 경계에 공통으로 적용하는 히스테리시스 폭을 `H`라고 한다.

- 변동성이 `T`를 초과하면 한 단계 낮은 TQQQ 목표 비중으로 이동한다.
- 축소된 상태에서는 변동성이 `T - H` 이하가 되어야 이전의 높은 비중으로 복귀한다.
- 하루에 여러 경계를 통과하면 중간 상태를 생략하고 조건을 만족하는 최종 상태로 이동한다.
- 상태 변경 신호는 종가까지의 데이터로 계산하고 주문은 다음 거래일 시가에 체결한다.
- 모든 경계에 하나의 `H`만 사용한다. 경계마다 다른 폭을 두지 않는다.

예를 들어 위험 축소 경계가 60%이고 `H=20%p`이면 변동성이 60%를 초과할 때 비중을 줄이고, 이후 40% 이하가 되어야 이전 비중으로 복귀한다.

`H=0`이면 히스테리시스를 사용하지 않는 기본 계단형 규칙과 같다. 히스테리시스는 거래를 줄이는 대신 위험 해제와 재진입을 늦출 수 있으므로 수익률 개선 규칙으로 간주하지 않고 후보별로 따로 검증한다.
